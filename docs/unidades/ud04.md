# Unidad 4. Programación Orientada a Objetos en Java

## Introducción

Los conceptos de Programación Orientada a Objetos (POO) que ya conoces de Python (clases, objetos, atributos y métodos) son exactamente los mismos en Java. Lo que cambia es la sintaxis y el nivel de rigor que impone el lenguaje.

En esta unidad aprenderás a aplicar los conocimientos que ya tienes de Python, comparando continuamente ambos lenguajes para facilitar la transición.

Las principales diferencias son:

- **Tipado estático**: hay que declarar el tipo de cada variable, atributo y parámetro.
- **Control de acceso real** mediante modificadores como `private`.
- **Getters y setters** para acceder a atributos privados.
- **Constructores** con el nombre de la clase en lugar de `__init__()`.
- Métodos especiales como `toString()`, `equals()` y `hashCode()`, equivalentes a `__str__()`, `__eq__()` y `__hash__()`.

---

# 4.1. Cómo se organiza el código

En Java existe una organización más estricta del código:

- Una clase `public` debe estar en un archivo con el mismo nombre.
- La clase `Alumno` debe almacenarse en `Alumno.java`.
- El programa comienza a ejecutarse en el método `main()`.

```java
public class Principal {

    public static void main(String[] args) {
        Alumno alumno1 = new Alumno("Ana", 18);
        alumno1.presentarse();
    }

}
```

## Comparativa Python vs Java

### Python

```python
print("Hola")
```

### Java

```java
public class Principal {

    public static void main(String[] args) {
        System.out.println("Hola");
    }

}
```

En Python es habitual escribir código directamente en el archivo. En Java, todo código ejecutable debe encontrarse dentro de una clase y de un método.

# 4.2. De Python a Java

La misma clase escrita en ambos lenguajes.

## Python

```python
class Alumno:

    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad

    def presentarse(self):
        print(f"Hola, me llamo {self.nombre}")


alumno1 = Alumno("Ana", 18)
alumno1.presentarse()
```

## Java

### Alumno.java

```java
public class Alumno {

    String nombre;
    int edad;

    public Alumno(String nombre, int edad) {
        this.nombre = nombre;
        this.edad = edad;
    }

    public void presentarse() {
        System.out.println("Hola, me llamo " + nombre);
    }

}
```

### Principal.java

```java
public class Principal {

    public static void main(String[] args) {

        Alumno alumno1 = new Alumno("Ana", 18);
        alumno1.presentarse();

    }

}
```

Los conceptos son idénticos:

- Una clase es una plantilla.
- Un objeto es una instancia concreta.
- Los atributos almacenan información.
- Los métodos definen comportamientos.

Java exige indicar explícitamente los tipos y utiliza la palabra clave `new` para crear objetos.

> **Simplificación temporal**
>
> En los primeros ejemplos los atributos no llevan `private`. Más adelante veremos la forma correcta de declararlos.

# 4.3. Clases, objetos y atributos

Una clase es una plantilla a partir de la cual se crean objetos.

```java
public class Videojuego {

    String titulo;
    String genero;
    double precio;

}
```

Creación de objetos:

```java
Videojuego juego1 = new Videojuego();
Videojuego juego2 = new Videojuego();
```

Cada objeto tiene sus propios valores:

```java
Alumno alumno1 = new Alumno("Ana", 18);

alumno1.nombre = "Ana";
alumno1.edad = 18;
```

## Valores por defecto

En Python un atributo no existe hasta que se crea.

En Java, los atributos tienen un valor inicial automático.

| Tipo | Valor por defecto |
|--------|--------|
| `int`, `long` | `0` |
| `double`, `float` | `0.0` |
| `boolean` | `false` |
| `String` y objetos | `null` |

```java
String nombre; // vale null
```

Intentar utilizar un objeto `null` provocará una excepción:

```text
NullPointerException
```

# 4.4. Métodos y constructores

## Métodos

Los métodos representan acciones.

```java
public void presentarse() {
    System.out.println("Hola, soy " + nombre);
}
```

Pueden devolver valores:

```java
public int getEdad() {
    return edad;
}
```

Uso:

```java
int edad = alumno1.getEdad();
```

## Constructor

### Python

```python
def __init__(self, nombre, edad):
```

### Java

```java
public Alumno(String nombre, int edad) {
    this.nombre = nombre;
    this.edad = edad;
}
```

Cuando ejecutamos:

```java
new Alumno("Ana", 18);
```

Java:

1. Reserva memoria.
2. Crea el objeto.
3. Llama automáticamente al constructor.

## Constructor por defecto

Si no escribimos ningún constructor:

```java
public class Alumno {

}
```

Java genera automáticamente:

```java
public Alumno() {

}
```

Si escribimos un constructor propio:

```java
public Alumno(String nombre, int edad) {

}
```

Entonces desaparece el constructor vacío.

## Sobrecarga de constructores

```java
public Alumno() {
    this("Sin nombre", 0);
}

public Alumno(String nombre, int edad) {
    this.nombre = nombre;
    this.edad = edad;
}
```

## La palabra reservada `this`

| Python | Java |
|----------|----------|
| `self` es obligatorio | `this` es opcional en muchos casos |
| `self.nombre` | `nombre` o `this.nombre` |
| Aparece en todos los métodos | Es implícito |

```java
this.nombre = nombre;
```

# 4.5. Encapsulación

La encapsulación consiste en proteger los datos internos de un objeto.

## Python

```python
self._nombre
```

o

```python
self.__nombre
```

Son convenciones que indican que no debería accederse desde fuera.

## Java

```java
private String nombre;
```

Ahora esto no compila:

```java
alumno.nombre = "Ana";
```

## Modificadores de acceso

| Modificador | Accesible desde |
|------------|------------|
| `private` | La propia clase |
| Sin modificador | Mismo paquete |
| `protected` | Paquete y subclases |
| `public` | Cualquier clase |

A partir de ahora utilizaremos:

```java
private String nombre;
private int edad;
```

# 4.6. Getters y Setters

Lectura:

```java
public String getNombre() {
    return nombre;
}
```

Modificación:

```java
public void setNombre(String nombre) {
    this.nombre = nombre;
}
```

Uso:

```java
Alumno alumno = new Alumno("Ana", 18);

alumno.setNombre("Ana María");

System.out.println(
    alumno.getNombre()
);
```

## Comparativa con Python

| Python | Java |
|----------|----------|
| `alumno.edad` | `alumno.getEdad()` |
| `alumno.edad = 20` | `alumno.setEdad(20)` |

## Validación

```java
public void setEdad(int edad) {

    if (edad < 0) {
        throw new IllegalArgumentException(
            "La edad no puede ser negativa: " + edad
        );
    }

    this.edad = edad;
}
```

## Validación desde el constructor

Incorrecto:

```java
public Alumno(String nombre, int edad) {
    this.nombre = nombre;
    this.edad = edad;
}
```

Correcto:

```java
public Alumno(String nombre, int edad) {
    this.nombre = nombre;
    setEdad(edad);
}
```

Así toda modificación pasa por las mismas reglas de validación.

# 4.7. toString() y @Override

Si imprimimos un objeto:

```java
System.out.println(alumno);
```

Java mostrará algo parecido a:

```text
Alumno@5fd0d5ae
```

## Sobrescribiendo toString()

```java
@Override
public String toString() {
    return nombre + " (" + edad + " años)";
}
```

Resultado:

```text
Ana (18 años)
```

## ¿Qué hace @Override?

Indica al compilador que estamos sobrescribiendo un método heredado.

```java
@Override
public String toString() {
    ...
}
```

Ayuda a detectar errores de escritura.

## Comparativa con Python

| Python | Java |
|----------|----------|
| `__str__()` | `toString()` |
| `print(objeto)` | `System.out.println(objeto)` |
| `__repr__()` | Sin equivalente directo |

### Equivalente a las f-strings

Python:

```python
f"{nombre} ({edad})"
```

Java:

```java
String.format("%s (%d)", nombre, edad);
```

# 4.8. Comparar objetos: == frente a equals()

Esta es una de las diferencias más importantes.

| Python | Java | Significado |
|----------|----------|----------|
| `a is b` | `a == b` | Mismo objeto |
| `a == b` | `a.equals(b)` | Igual contenido |

Ejemplo:

```java
Alumno a1 = new Alumno("Ana", 18);
Alumno a2 = new Alumno("Ana", 18);

System.out.println(a1 == a2);
System.out.println(a1.equals(a2));
```

Salida:

```text
false
true
```

## Caso especial: String

```java
String s1 = "a";
String s2 = new String("a");

System.out.println(s1 == s2);
System.out.println(s1.equals(s2));
```

Salida:

```text
false
true
```

> **Regla práctica**
>
> Para comparar objetos, incluyendo `String`, utiliza siempre `equals()`.

# 4.9. equals() y hashCode()

## equals()

```java
@Override
public boolean equals(Object obj) {

    if (this == obj) {
        return true;
    }

    if (obj == null || getClass() != obj.getClass()) {
        return false;
    }

    Alumno otro = (Alumno) obj;

    return Objects.equals(nombre, otro.nombre)
            && edad == otro.edad;
}
```

## hashCode()

```java
@Override
public int hashCode() {
    return Objects.hash(nombre, edad);
}
```

## Equivalencia con Python

| Python | Java |
|----------|----------|
| `__eq__()` | `equals()` |
| `__hash__()` | `hashCode()` |

> **Regla fundamental**
>
> Si sobrescribes `equals()`, debes sobrescribir también `hashCode()`.

# 4.10. Relaciones entre objetos

Hasta ahora hemos creado objetos aislados. Sin embargo, en los programas reales los objetos interactúan entre sí.

Por ejemplo:

- Un vehículo tiene un motor.
- Un alumno pertenece a un grupo.
- Un pedido contiene productos.

La solución orientada a objetos consiste en relacionar clases mediante referencias.

---

# 4.11. El concepto de referencia entre objetos

Hasta ahora hemos trabajado con atributos de tipos simples (`int`, `String`, `double`, `boolean`).

Sin embargo, un atributo también puede almacenar una referencia a otro objeto:

```java
public class Vehiculo {

    private int id;
    private String marca;
    private Motor motor;

}
```

## Encadenamiento de llamadas

```java
coche.getMotor().getModelo();
```

Paso a paso:

1. `coche.getMotor()` devuelve un objeto `Motor`.
2. `.getModelo()` obtiene el modelo de ese motor.

---

# 4.12. Creación y uso de objetos relacionados

```java
Motor motor1 = new Motor(
        1,
        "TDI",
        2000
);

Vehiculo coche = new Vehiculo(
        100,
        "Volkswagen",
        motor1
);

System.out.println(
        coche.getMotor()
              .getModelo()
);
```

Salida:

```text
TDI
```

---

# 4.13. Referencias y el valor null

Cuando una referencia no apunta a ningún objeto, vale `null`.

```java
Vehiculo coche = new Vehiculo(
        100,
        "Ford",
        null
);
```

## El peligro de la NullPointerException

```java
System.out.println(
        coche.getMotor()
              .getModelo()
);
```

Si el vehículo no tiene motor:

```text
NullPointerException
```

## Buena práctica

```java
if (coche.getMotor() != null) {

    System.out.println(
            coche.getMotor()
                  .getModelo()
    );

} else {

    System.out.println(
            "El vehículo no tiene motor asignado."
    );

}
```

# 4.14. Multiplicidad: ¿Uno o muchos?

Al diseñar una relación debemos preguntarnos:

> ¿Cuántos objetos participan en la relación?

| Situación | Modelado en Java | Ejemplo |
|------------|------------|------------|
| Uno a uno (1:1) | Atributo simple | `private Motor motor;` |
| Uno a muchos (1:N) | `ArrayList` | `private ArrayList<Rueda> ruedas;` |

Ejemplo:

```java
import java.util.ArrayList;

public class Vehiculo {

    private int id;
    private String marca;
    private Motor motor;
    private ArrayList<Rueda> ruedas;

}
```

# 4.15. Direccionalidad: ¿Quién conoce a quién?

## Relación unidireccional

Solo una clase conoce a la otra.

```text
Vehiculo ---> Motor
```

```java
coche.getMotor();
```

Es la opción más habitual.

## Relación bidireccional

Ambas clases almacenan referencias mutuas.

```text
Vehiculo <----> Motor
```

```java
vehiculo.getMotor();

motor.getVehiculo();
```

Solo debe utilizarse cuando sea realmente necesario navegar en ambos sentidos.

# 4.17. Clase completa de ejemplo

## Alumno.java

```java
import java.util.Objects;

public class Alumno {

    private String nombre;
    private int edad;

    public Alumno(String nombre, int edad) {
        this.nombre = nombre;
        setEdad(edad);
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }

    public int getEdad() {
        return edad;
    }

    public void setEdad(int edad) {

        if (edad < 0) {
            throw new IllegalArgumentException(
                    "La edad no puede ser negativa: " + edad);
        }

        this.edad = edad;
    }

    @Override
    public String toString() {
        return String.format(
                "%s (%d años)",
                nombre,
                edad);
    }

    @Override
    public boolean equals(Object obj) {

        if (this == obj) {
            return true;
        }

        if (obj == null || getClass() != obj.getClass()) {
            return false;
        }

        Alumno otro = (Alumno) obj;

        return Objects.equals(nombre, otro.nombre)
                && edad == otro.edad;
    }

    @Override
    public int hashCode() {
        return Objects.hash(nombre, edad);
    }

}
```

## Principal.java

```java
import java.util.HashSet;
import java.util.Set;

public class Principal {

    public static void main(String[] args) {

        Alumno a1 = new Alumno("Ana", 18);
        Alumno a2 = new Alumno("Ana", 18);

        System.out.println(a1);

        System.out.println(a1 == a2);
        System.out.println(a1.equals(a2));

        Set<Alumno> grupo = new HashSet<>();

        grupo.add(a1);
        grupo.add(a2);

        System.out.println(grupo.size());

        a1.setEdad(-5);

    }

}
```

# Errores típicos de quien viene de Python

| Error | Corrección |
|---------|---------|
| Comparar objetos con `==` | Utilizar `equals()` |
| Comparar `String` con `==` | Utilizar `equals()` |
| Llamar a `new Alumno()` sin constructor vacío | Crear constructor sin parámetros |
| Sobrescribir `equals()` sin `hashCode()` | Sobrescribir ambos |
| Saltarse la validación en el constructor | Utilizar setters |
| Utilizar una referencia `null` | Inicializar o comprobar antes |
| Escribir código fuera de métodos | Colocarlo dentro de `main()` |
| Colocar una clase `public` en otro archivo | Nombre de clase y archivo deben coincidir |
| Invocar métodos sobre una referencia `null` | Comprobar con `if` antes de acceder |
| Crear relaciones bidireccionales innecesarias | Preferir relaciones unidireccionales |
| Guardar muchos objetos en atributos duplicados | Utilizar clases relacionadas |
