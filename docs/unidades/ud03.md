# Unidad 3. Métodos en Java para Programadores de Python

## 1. Introducción

Ya conoces las funciones en Python y has trabajado con ellas para dividir programas en partes más pequeñas y reutilizables.

En Java el concepto es exactamente el mismo. La diferencia principal es que Java es un lenguaje de **tipado estático**, por lo que debemos indicar explícitamente:

- El tipo de dato que devuelve el método.
- El tipo de cada parámetro.
- Algunos modificadores como `public` y `static`.

A lo largo de esta unidad aprenderás a crear y utilizar métodos en Java estableciendo continuamente la relación con las funciones de Python.

---

# 2. De las funciones de Python a los métodos de Java

## Función en Python

**Comparativa de función basica:**

=== "Python"
    ```python
    def sumar(a, b):
        return a + b
    ```
=== "Java"
    ```java
    public static int sumar(int a, int b) {
        return a + b;
    }
    ```



Observa las diferencias:

- En Python se utiliza `def`.
- En Java se indica primero el tipo de dato que devolverá el método.
- Los parámetros deben tener un tipo declarado.
- Los bloques se delimitan mediante llaves `{}`.
- Cada instrucción termina con `;`.

---

# 3. Anatomía de un método

Ejemplo:

```java
public static int sumar(int a, int b) {
    return a + b;
}
```

Partes del método:

```java
public static int sumar(int a, int b) {
```

### public

Indica que el método puede utilizarse desde cualquier parte del programa.

### static

Permite utilizar el método sin crear objetos.

Durante esta etapa trabajaremos siempre con métodos `static`.

### int

Es el tipo de dato que devuelve el método.

### sumar

Es el nombre del método.

### int a, int b

Son los parámetros de entrada.

### return

Devuelve el resultado al programa que llamó al método.

---

# 4. Métodos que devuelven valores

Un método que devuelve información debe utilizar la instrucción `return`.


**Comparativa de devolución de valor:**

=== "Python"
    ```python
    def multiplicar(a, b):
        return a * b
    ```
=== "Java"
    ```java
    public static int multiplicar(int a, int b) {
        return a * b;
    }
    ```



Uso en Java:

```java
int resultado = multiplicar(4, 5);

System.out.println(resultado);
```

Salida:

```text
20
```

---

# 5. Métodos que no devuelven valores

A veces un método simplemente realiza una acción.

**Comparativa de funciones void:**

=== "Python"
    ```python
    def saludar(nombre):
        print("Hola", nombre)
    ```
=== "Java"
    ```java
    public static void saludar(String nombre) {
        System.out.println("Hola " + nombre);
    }
    ```


Uso en Java:

```java
saludar("Ana");
```

Salida:

```text
Hola Ana
```

### El tipo void

Cuando un método no devuelve ningún valor se utiliza el tipo:

```java
void
```

Por tanto:

- `int`, `double`, `String`... → devuelven algo.
- `void` → no devuelve nada.

# 6. Llamada a métodos

Para ejecutar un método debemos escribir su nombre seguido de paréntesis.

Ejemplo:

```java
public static int cuadrado(int numero) {
    return numero * numero;
}
```

Llamadas:

```java
int a = cuadrado(3);

int b = cuadrado(8);

System.out.println(a);
System.out.println(b);
```

Salida:

```text
9
64
```

# 9. Ámbito de las variables (Scope)

Las variables declaradas dentro de un método solo existen dentro de ese método.

**Comparativa:**

=== "Python"
    ```python
    def ejemplo():
        x = 10

    print(x)
    ``` 
    Produce error porque `x` solo existe dentro de la función.
=== "Java"
    ```java
    public static void ejemplo() {
        int x = 10;
    }

    System.out.println(x);
    ```
    También produce error por el mismo motivo.




## Variables locales

```java
public static void mostrar() {

    int numero = 5;

    System.out.println(numero);
}
```

La variable `numero` solo existe dentro del método `mostrar()`.

# 10. Paso de parámetros en Java

Una idea importante para los programadores que vienen de Python:

> Java siempre pasa los argumentos por valor.

Sin embargo, debemos distinguir entre tipos primitivos y referencias.

## Tipos primitivos

Ejemplo:

```java
public static void duplicar(int numero) {
    numero = numero * 2;
}
```

Programa principal:

```java
int x = 10;

duplicar(x);

System.out.println(x);
```

Salida:

```text
10
```

El valor original no cambia porque Java copia el contenido de la variable.

## Arrays

```java
public static void incrementar(int[] datos) {

    datos[0]++;

}
```

Programa principal:

```java
int[] valores = {10, 20, 30};

incrementar(valores);

System.out.println(valores[0]);
```

Salida:

```text
11
```

En este caso se copia la referencia al array, por lo que podemos modificar sus elementos.

# 11. Métodos y arrays

Es muy habitual trabajar con arrays desde métodos.

## Calcular suma

```java
public static int sumarArray(int[] numeros) {

    int suma = 0;

    for (int n : numeros) {
        suma += n;
    }

    return suma;
}
```

Uso:

```java
int[] datos = {3, 5, 8, 2};

System.out.println(sumarArray(datos));
```

Salida:

```text
18
```

# 12. ¿Por qué usamos static?

Los estudiantes que conocen Python suelen hacerse esta pregunta.

En Python una función puede existir por sí sola:

```python
def sumar(a, b):
    return a + b
```

En Java todo debe pertenecer a una clase.

```java
public class Utilidades {

    public static int sumar(int a, int b) {
        return a + b;
    }

}
```

Como todavía no hemos estudiado programación orientada a objetos, utilizaremos métodos `static`.

Más adelante aprenderás a crear métodos asociados a objetos.

# 15. Resumen Python → Java

- `def` → `public static`
- Sin indicar tipos → Tipos obligatorios
- `return` → `return`
- Sin `return` → `void`
- `list` → `array`
- `len(lista)` → `array.length`
- `for x in lista` → `for (tipo x : array)`
- Tipado dinámico → Tipado estático
- `input()` → `Scanner`
- `print()` → `System.out.println()`
- Indentación → Llaves `{ }`
- Funciones independientes → Métodos dentro de clases

## Ideas clave

1. Los métodos de Java cumplen el mismo papel que las funciones de Python.
2. Java exige declarar los tipos de datos.
3. Los métodos pueden devolver valores o ser `void`.
4. Las variables locales solo existen dentro de su método.
5. Los arrays pueden enviarse como parámetros.
6. Utilizar métodos mejora la organización, reutilización y mantenimiento del código.

# Anexo: Sobrecarga de Métodos (Comparación Python - Java)

## ¿Por qué existe la sobrecarga?

Cuando programamos, muchas veces queremos realizar la misma operación con distintos tipos de datos.

Por ejemplo:

- Sumar enteros.
- Sumar decimales.
- Sumar tres números en lugar de dos.

En Java podemos reutilizar el mismo nombre de método mediante la **sobrecarga de métodos**.

---

# ¿Qué ocurre en Python?

En Python no existe la sobrecarga tradicional de métodos.

Por ejemplo:

```python
def saludar(nombre):
    print("Hola", nombre)

def saludar(nombre, edad):
    print("Hola", nombre, "tienes", edad, "años")
```

Parece que hemos definido dos funciones distintas.

Sin embargo, la segunda sustituye completamente a la primera.

Si intentamos ejecutar:

```python
saludar("Ana")
```

obtendremos un error.

Solo existe la última definición.

---

# ¿Cómo se resuelve normalmente en Python?

Habitualmente utilizando parámetros opcionales.

```python
def saludar(nombre, edad=None):

    if edad is None:
        print("Hola", nombre)
    else:
        print("Hola", nombre, "tienes", edad, "años")
```

Uso:

```python
saludar("Ana")
saludar("Luis", 18)
```

Salida:

```text
Hola Ana
Hola Luis tienes 18 años
```

---

# La solución en Java: Sobrecarga

En Java podemos definir varios métodos con el mismo nombre.

```java
public static void saludar(String nombre) {

    System.out.println("Hola " + nombre);

}

public static void saludar(String nombre, int edad) {

    System.out.println("Hola " + nombre +
                       ", tienes " + edad + " años");

}
```

Uso:

```java
saludar("Ana");

saludar("Luis", 18);
```

Salida:

```text
Hola Ana
Hola Luis, tienes 18 años
```

Java decide automáticamente qué método ejecutar.

---

# Sobrecarga por número de parámetros

Una forma de sobrecargar consiste en cambiar la cantidad de parámetros.

## Python

Habitualmente haríamos:

```python
def sumar(a, b, c=None):

    if c is None:
        return a + b

    return a + b + c
```

## Java

```java
public static int sumar(int a, int b) {
    return a + b;
}

public static int sumar(int a, int b, int c) {
    return a + b + c;
}
```

Uso:

```java
System.out.println(sumar(2, 3));

System.out.println(sumar(2, 3, 4));
```

Salida:

```text
5
9
```

---

# Sobrecarga por tipo de parámetros

También podemos cambiar el tipo de datos.

## En Python

No suele ser necesario porque el lenguaje es dinámico.

```python
def mostrar(valor):
    print(valor)
```

La misma función acepta distintos tipos.

```python
mostrar(10)
mostrar(3.14)
mostrar("Hola")
```

## En Java

Como existe tipado estático, podemos crear varias versiones.

```java
public static void mostrar(int valor) {
    System.out.println("Entero: " + valor);
}

public static void mostrar(double valor) {
    System.out.println("Decimal: " + valor);
}
```

Uso:

```java
mostrar(10);

mostrar(3.14);
```

# Ejemplo práctico

Supongamos que queremos calcular áreas.

## Python

```python
def area(base, altura=None):

    if altura is None:
        return base * base

    return base * altura
```

Uso:

```python
area(5)
area(4, 6)
```

## Java

```java
public static double area(double lado) {
    return lado * lado;
}

public static double area(double base,
                          double altura) {
    return base * altura;
}
```

Uso:

```java
area(5);

area(4, 6);
```

---

# ¿Qué NO cuenta como sobrecarga?

Los parámetros deben ser distintos.

Esto es incorrecto:

```java
public static int calcular(int x) {
    return x * 2;
}

public static double calcular(int x) {
    return x * 2;
}
```

Produce un error de compilación.

Aunque cambia el tipo de retorno, los parámetros son exactamente iguales.

---

# ¿Cómo decide Java qué método ejecutar?

Java observa los argumentos de la llamada.

```java
public static void imprimir(int x) {
    System.out.println("int");
}

public static void imprimir(double x) {
    System.out.println("double");
}
```

Llamadas:

```java
imprimir(5);

imprimir(5.0);
```

Salida:

```text
int
double
```

Porque:

- `5` es un `int`
- `5.0` es un `double`

---


# Ideas clave

1. Python normalmente utiliza parámetros opcionales para resolver estos casos.
2. Java utiliza sobrecarga de métodos.
3. Los métodos pueden tener el mismo nombre si sus parámetros son diferentes.
4. Puede variar:
   - El número de parámetros.
   - El tipo de parámetros.
5. El tipo de retorno no es suficiente para sobrecargar un método.
6. La sobrecarga permite escribir código más claro y más fácil de reutilizar.
