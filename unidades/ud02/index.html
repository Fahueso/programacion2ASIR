    Unidad 2 - Programación Estructurada: Estructuras de Control y Repetición

    Objetivos de la Unidad

    Al finalizar esta unidad, el desarrollador podrá trasladar sus competencias en Python al ecosistema de Java, siendo capaz de: - Implementar la programación modular y estructurada bajo un modelo de tipado estático. - Implementar en Java las tres estructuras de control: secuencial, condicional y repetitiva, gestionando la diferencia entre iteradores abstractos y control de índices. - Usar arrays unidimensionales (vectores) y bidimensionales (matrices), comprendiendo la asignación de memoria estática frente a la dinámica. - Manipular cadenas de texto con los métodos de la clase String, distinguiendo entre comparación de referencias y de valores.

    1 Introducción: Construyendo programas sólidos

    En esta unidad sentaremos las bases para crear programas que no solo funcionen, sino que sean claros, sencillos de mantener y fáciles de ampliar. Para un programador que viene de Python, el desafío aquí no es la lógica, sino la rigidez del lenguaje.

    En Java, la solidez se consigue mediante el tipado estático, lo que significa que el compilador nos obliga a ser explícitos con cada dato. Esto reduce drásticamente los errores de tipo que en Python solo descubriríamos en tiempo de ejecución.

    2 Programación Modular: Construyendo con piezas de LEGO

    La programación modular consiste en dividir un programa complejo en partes más pequeñas e independientes, llamadas módulos.

    En Python, solemos crear módulos mediante funciones independientes en archivos .py. En Java, la modularidad es más estricta: todo debe residir dentro de una Clase, y los módulos se implementan como Métodos.

    2.1 Gestión de Dependencias: Los import

    Para utilizar herramientas que no pertenecen al núcleo básico de Java, debemos importar la clase específica desde su paquete. A diferencia de Python, donde se pueden importar funciones sueltas, en Java importamos la Clase completa.

    El paquete java.lang

    Existe un paquete llamado java.lang que contiene las clases más fundamentales (como String, Math o System). Este paquete es el único que se importa automáticamente en todos los archivos; por ello, no necesitas importar nada para usar Math.sqrt() o Math.PI.

    3 Programación Estructurada: Las reglas de tráfico del código

    La programación estructurada nos dice cómo construir cada una de esas divisiones. Se basa en el Teorema de la Estructura, que demuestra que cualquier programa, por complejo que sea, puede construirse usando únicamente tres tipos de estructuras de control.

    Para un programador de Python, la lógica de estas estructuras es idéntica, pero la implementación en Java requiere un cambio en la sintaxis de los bloques (pasando de la indentación a las llaves {}).

    Estructura Analogía Descripción Implementación en Python Implementación en Java
    Secuencial Calle de sentido único Las instrucciones se ejecutan una tras otra, en orden Indentación y saltos de línea Llaves { } y punto y coma ;
    Condicional Bifurcación El programa decide qué camino tomar según una condición if, elif, else if, else if, else, switch
    Repetitiva Rotonda El programa repite un bloque hasta que se cumple la condición de salida while, for while, do-while, for

    Diferencia Clave de Sintaxis

    Mientras que en Python la estructura es visual (si el código está movido a la derecha, pertenece al bloque), en Java la estructura es explícita. Esto significa que puedes escribir todo el código en una sola línea y el programa seguiría funcionando, ya que el compilador se guía por las llaves {} y no por los espacios.

    A diferencia de Python, donde el código puede ejecutarse de forma lineal desde la primera línea del archivo, Java requiere una estructura jerárquica obligatoria. El "Inicio" real de cualquier programa es el método main.

    El concepto del punto de entrada y el if __name__ == "__main__"

    En Python, es habitual utilizar if __name__ == "__main__": para diferenciar si un archivo se ejecuta como script principal o se importa como módulo. En Java, esta distinción es una regla arquitectónica:

    1. No existen los "scripts" sueltos: Todo código debe residir dentro de una clase.
    2. El método main es el estándar: La JVM (Java Virtual Machine) busca específicamente la firma public static void main(String[] args). Si este método no existe, el programa no puede iniciarse como aplicación.

    Ejemplo de traducción de lógica de ejecución:

    Análisis Técnico de la firma del main

    • public: Permite que la JVM acceda al método desde fuera de la clase.
    • static: Permite que el método se ejecute sin necesidad de instanciar la clase.
    • void: Indica que el método no devuelve ningún valor.
    • String[] args: Array que recibe los argumentos pasados por consola (equivalente a sys.argv).

    4.4 Estructuras Alternativas (Condicionales)

    Las estructuras condicionales permiten que el programa tome decisiones y ejecute diferentes bloques de código según se cumpla o no una condición. Aunque la lógica es la misma que en Python, Java es más estricto: la condición debe estar entre paréntesis () y el bloque de código debe estar delimitado por llaves {}.

    4.4.1 Condicional if (Simple) y if-else (Doble)

    El if ejecuta un bloque si la condición es verdadera. El else proporciona un camino alternativo si la condición es falsa.

    El peligro del Fall-through

    Si olvidas la sentencia break al final de un case, Java no se detendrá; continuará ejecutando los bloques de los casos siguientes aunque la condición no se cumpla. Esto se conoce como fall-through y es una fuente común de errores.

    4.5 Estructuras Repetitivas (Bucles)

    Los bucles permiten ejecutar un bloque de código múltiples veces. Aunque la lógica de repetición es la misma que en Python, Java ofrece un control mucho más granular sobre el índice y la condición de parada.

    4.5.1 Bucle while (Mientras)

    El while es la estructura más similar entre ambos lenguajes. Repite el bloque mientras la condición sea verdadera. La condición se evalúa antes de entrar al bucle.

    Comparativa de sintaxis:

    1

    print(f"Vuelta {contador}")
    contador += 1

    4.5.2 Bucle do-while (Hacer-Mientras)

    Concepto nuevo para Pythonistas: En Python no existe un equivalente directo. El do-while garantiza que el bloque de código se ejecute al menos una vez, ya que la condición se evalúa al final.

    Es la estructura ideal para crear menús de usuario, donde quieres mostrar las opciones al menos una vez antes de preguntar si el usuario desea salir.

    Ejemplo de implementación en Java:

    System.out.println("--- MENÚ PRINCIPAL ---");

    opcion = teclado.nextInt();
} while (opcion != 2); // El bucle se repite mientras la opción NO sea 2

    4.5.3 Bucle for (Para)

    Aquí es donde ocurre el mayor cambio de paradigma. En Python, el for itera sobre una secuencia. En Java, el for clásico es un controlador de índices.

    Traducción de patrones de range():

    Patrón en Python Implementación en Java Explicación Técnica
    range(10) for (int i=0; i<10; i++) Inicia en 0, termina antes de 10, aumenta de 1 en 1.
    range(5, 15) for (int i=5; i<15; i++) Inicia en 5, termina antes de 15, aumenta de 1 en 1.
    range(0, 10, 2) for (int i=0; i<10; i+=2) Inicia en 0, termina antes de 10, aumenta de 2 en 2.
    range(10, 0, -1) for (int i=10; i>0; i--) Inicia en 10, termina antes de 0, disminuye de 1 en 1.

    Ejemplo Comparativo: Tabla de multiplicar

    4.5.4 El Enhanced For (For-each)

    Cuando no necesitamos el índice i y solo queremos recorrer todos los elementos de una colección, Java ofrece una sintaxis simplificada que es prácticamente idéntica al for de Python.

    Comparativa de iteración de colecciones:

    1
2
3

    print(fruta)

    1
2
3
4
    String[] frutas = {"Manzana", "Pera", "Uva"};
for (String fruta : frutas) {
    System.out.println(fruta);
}

    Resumen de elección de bucle

    • ¿No sabes cuántas vueltas darás y depende de una condición? $\rightarrow$ while.
    • ¿Necesitas que el código se ejecute al menos una vez (ej. un menú)? $\rightarrow$ do-while.
    • ¿Sabes exactamente el número de repeticiones o necesitas el índice? $\rightarrow$ for clásico.
    • ¿Solo quieres recorrer todos los elementos de un array sin importar la posición? $\rightarrow$ for-each.

    5 Vectores y Matrices: Almacenando Datos en Colección

    Hasta ahora, cada variable guardaba un solo dato. Para almacenar colecciones, Java utiliza los Arrays. Sin embargo, para un programador de Python, es fundamental entender que un Array de Java NO es una Lista de Python.

    5.1 Vectores (Arrays Unidimensionales)

    En Python, una lista es un objeto dinámico que puede crecer, encoger y contener diferentes tipos de datos. En Java, un Array es una estructura estática y homogénea.

    A. La diferencia de memoria: Estático vs. Dinámico

    Cuando creas un array en Java, el sistema reserva un bloque de memoria contiguo y fijo. No puedes añadir más elementos una vez creado.

    5.2 Matrices (Arrays Bidimensionales)

    En Python, una matriz es simplemente una "lista de listas". En Java, es un array donde cada elemento es, a su vez, otro array.

    A. Análisis Comparativo: El choque de paradigmas

    Diferencias Críticas

    • En Python: Una matriz puede ser heterogénea (una fila de enteros y otra de strings) y dinámica (puedes añadir una fila nueva con .append()).
    • En Java: Una matriz es un bloque de memoria homogéneo. Si defines una matriz de int, absolutamente todos los elementos deben ser enteros. Además, su estructura (filas x columnas) es inmutable.

    B. Declaración y Acceso

    Para localizar un dato en una matriz, necesitamos dos coordenadas: la fila y la columna.

// Asignación: Fila 0, Columna 2
matriz[0][2] = 50;

    En Python, es común iterar sobre los objetos. En Java, la norma profesional es iterar sobre los índices. Esto es vital porque nos permite saber exactamente en qué posición estamos para modificar el dato.

    Acceso l[i] a[i] Idéntico.
    Matrices l[f][c] a[f][c] Idéntico, pero el tamaño es fijo.

    Consejo para el alumno

    Si en tu programa de Java necesitas que una colección crezca dinámicamente (como hacías con .append() en Python), no uses un Array []. Deberás utilizar la clase ArrayList, que es la implementación de Java que imita el comportamiento de las listas de Python.

    6 Strings: Cadenas de texto

    En Java, un String no es un tipo de dato primitivo (como int o boolean), sino que es un Objeto. Esta distinción es la razón por la cual la comparación de textos es diferente a lo que estamos acostumbrados en Python.

    6.1 Identidad vs. Igualdad

    Para entender cómo comparar strings en Java, primero debemos recordar cómo funciona Python. En Python, el operador == compara el contenido, mientras que el operador is compara la identidad (la dirección de memoria).

    En Java, el operador == NO compara el contenido, sino la identidad.

    Comparativa de Operadores:

    Objetivo Python Java Resultado
    Comparar Contenido s1 == s2 s1.equals(s2) ¿El texto es el mismo?
    Comparar Identidad s1 is s2 s1 == s2 ¿Apuntan al mismo lugar en memoria?

    Ejemplo Técnico Detallado:

    1
2
3
4
5
    s1 = "Hola"
s2 = "Hola"

print(s1 == s2) # True  (Contenido igual)
print(s1 is s2) # True  (Python optimiza strings cortos)

    1
2
3
4
5
6
7

    String s1 = "Hola";
String s2 = new String("Hola"); // Forzamos la creación de un objeto nuevo

// ERROR COMÚN: Comparar contenido con ==
System.out.println(s1 == s2);      // false (Son objetos distintos en memoria)

// FORMA CORRECTA: Usar .equals()
